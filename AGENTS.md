# GenAI-Test-Script-Automation

> **Audience**: LLM-driven agents

## Rules

1. **Language**: Python ≥ 3.13
2. **Package management**: ONLY use `uv`, NEVER `pip`
3. **Type safety**: All functions require type hints
4. **Line length**: 88 characters maximum
5. **Commits**: Never mention tools/AI
6. **Commit Type**: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `chore:`
7. **Naming**: `snake_case` functions, `PascalCase` classes
8. **File hygiene**: Prefer editing existing files over creating new ones
