# Login User with Incorrect Credentials

urls = ["http://automationexercise.com","https://automationexercise.com/login"]

## Steps

1. Launch browser and navigate to url 'http://automationexercise.com'
2. Verify that the home page is visible successfully
3. Click on the 'Signup / Login' button
4. Verify that the 'Login to your account' section is visible
5. Enter an incorrect email and an incorrect password
6. Click the 'Login' button
7. Verify that the error message 'Your email or password is incorrect!' is visible
